# 탱커 (가제)

> 공격 스킬이 하나도 없는 탱커가 되어, AI 팀원들을 지키며 던전을 클리어하는 모바일 턴제 게임.

## 현재 상태 (2026-08-16)

- **v0.4 대격변 (코어 가동 확인)** — 유저 지시로 라이브 지향 개편:
  **랜덤 파티**(나 + 클래스 7종 중 2~4명, 시드 결정) · **적 풀 9종 + 예산 기반 랜덤 조우 + 스테이지 스케일링** ·
  **덱빌딩**(카드 9종, 매 턴 3드로우 1사용, 전투 보상으로 덱 성장, 상점 카드 제거). 파티 소개/카드 보상 화면 신규.
  스모크 검증: 5인 파티 생성 → 랜덤 조우(샤먼 저주 인텐트) → 카드 예약-커밋 해소 → 리셔플까지 인게임 확인.
- **발열 해결**: 프레임 캡 없던 것이 원인 — `targetFrameRate=60` + UI 텍스트 10Hz 스로틀 적용. 게임 자체는 가벼움.
- **신규 에셋 18종 통합 완료**(클래스 5·적 4 × idle/공격) — codex 생성 → pixelize 하단 정렬 → 인게임 확인까지.
- 남은 것: v0.4 풀 런 밸런스 패스, TestFlight 업로드(유저 액션 2가지 대기 — `docs/dev.md` 빌드 & TestFlight 참고).

## 이전 상태 (2026-08-15)

- **v0.3.1 — 타이틀부터 엔딩까지 완주 가능한 런 구조 완성 + 적대적 리뷰 3회 통과분 반영**: 타이틀 → 던전 맵(7노드: 전투3·함정 이벤트·상점/휴식 갈림길·엘리트·휴식·보스) → 승리/패배 엔딩.
  아군 HP는 노드 간 유지(탱커 HP = 런의 수명), 골드/상점 업그레이드 4종, 보스 3턴 패턴(차징-광역-강타)+격노.
- **전 유닛 스프라이트 시트 애니메이션** (idle/공격/차징/버티기 + 타격·힐 FX + 프레임 하단 정렬로 지터 제거),
  던전 배경, 돌+금 프레임 UI 스킨(패널/버튼 9-slice). 에셋 전부 codex(GPT) 생성 + `pixelize.py` 후처리.
- **v0.3.2 — 밸런스 게이트 확정**: 레포 내장 결정론 탐색기(`TankerBalanceSearch`)로 무손실 엔진 2건을 재현·제거.
  확정 룰: 힐러는 백라이너 전담(탱커 치료 안 함) + 버티기 회복은 받은 만큼 후불. 전투별 최적 상한 측정으로 "어렵지만 공정" 판정.
- **아키텍처 규약(신규)**: VSA 슬라이스(Battle/Run/Shared), 밸런스 수치는 `Resources/balance.json` 단일 출처(하드코딩 금지),
  다국어 ko/en(`Loc`, 타이틀에서 전환), 최적화 최우선 검토. macOS 스탠드얼론 빌드 검증 완료(빌드 시점 씬 생성).
- 다음 관문: **유저 직접 플레이 재미 판정** (v0.3.2는 어렵습니다 — 탱커 회복원이 버티기·휴식·물약뿐) → 사운드, 노드 분기, 딜러/힐러 개성.
- 저장소: https://github.com/dongmin1213/tanker (private)

## 구조

```
tanker/
├─ unity/                 # Unity 프로젝트 — VSA 슬라이스: Scripts/Battle(전투)·Run(런)·Shared(UiKit/Balance/Loc/부트)
│                         #   수치는 Resources/balance.json, 문자열은 Loc(ko/en), 에셋은 Resources/Art
├─ tools/
│  ├─ mcp_unity.py        # Unity MCP stdio 클라이언트 (Claude 개발 루프용)
│  ├─ unity-snippets/     # RunCommand 스니펫 (play/stop/refresh/상태/캡처 등)
│  └─ pixelize.py         # AI 생성 이미지 → 게임용 픽셀 스프라이트 후처리
└─ docs/
```
