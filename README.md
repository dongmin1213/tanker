# 탱커 (가제)

> 공격 스킬이 하나도 없는 탱커가 되어, AI 팀원들을 지키며 던전을 클리어하는 모바일 턴제 게임.

## 확정된 것

- **장르**: 턴제, 싱글플레이, 던전 클리어형
- **파티**: 팀원은 완전 AI (딜은 팀원이, 나는 보호만)
- **플랫폼**: 모바일, 세로(포트레이트) 고정, 스크롤/줌 없는 한 화면
- **전투 뷰**: 그리드 대신 사이드뷰 파티 전투 (다키스트 던전/슬더스 계열)
  - 상단 = 전투 영역 (~55%): 왼쪽 아군, 오른쪽 적군(1~n)
  - 하단 = 이번 턴 선택지 (~45%): 스킬 카드/버튼 + 턴 종료, 엄지 존
  - 위치감은 전열/후열 개념 정도만 (밀치기/자리바꾸기 스킬용)
- **엔진**: Unity 6 LTS (2026-08-15 확정)
  - MCP는 공식 베타(`com.unity.ai.assistant` 내장, Unity 6.0.66f2+ 권장)부터 시도, 품질 문제 시 CoplayDev/unity-mcp로 전환
  - 근거: 한국 모바일 업계 표준 + 포트폴리오 가치 + Unity MCP로 Claude 개발 루프 가능해짐
- **개발 분담**: 코드 = Claude(Unity MCP 경유), 에셋 = Codex(GPT 이미지 생성)
- **애니메이션 전략**: 정지 스프라이트 1~2장 + 코드 트윈(숨쉬기, 피격 플래시, 쏠림).
  프레임 애니메이션은 AI 생성 일관성 문제로 배제.

## 핵심 디자인 원칙

1. **적의 인텐트(누가 누굴 얼마나 때릴지)는 항상 공개** — 적→타겟 화살표 + 예상 데미지. 수읽기 게임의 전제.
2. **스킬 선택 시 화살표가 나에게로 휘는 미리보기** — 이 게임의 "타격감". 2단계 커밋(탭→미리보기→확정) + 실행취소 필수.
3. **어그로가 자원** — 도발은 코스트/쿨다운이 있어서 "누굴 구할지" 강제 선택이 생겨야 함.
4. **내 HP가 소모 자원** — 맞아주는 것 자체가 지출.
5. **팀원은 맞으면 위축돼서 딜 감소/턴 손실** — 보호 = DPS 등식.
6. **방어 피드백이 공격보다 크게** — "-14 막음!", "이번 턴 구한 목숨: 1". 공허함 방지.

## 탱커의 동사 (초안)

도발(타겟을 나로) / 엄호(아군 대신 맞기) / 보호막 부여 / 자세 전환(방어↔어그로) / 밀치기·자리바꾸기(열 이동)

## 리서치 요약 (2026-08-13)

- **Don't Lose Aggro** (Steam EA, 매우 긍정적): 탱커-온리 싱글 판타지 검증. 단, 실시간 액션 + 공격 스킬 있음 → 우리와 차별점: "수읽기로 하는 탱킹" + 공격 제로.
- **Hexnaut** (itch.io): 공격 불가 턴제 로그라이크 성립 증거. 단, 지킬 파티 없음.
- **힐러-온리 장르** (Healer's Quest, Mini Healer 등): "한 역할만 + AI 파티" 틀 검증.
- 턴제+공격제로+AI파티 교집합은 빈 자리. 니치 천장은 낮음 (상업 대박용 아님).

## 최소 에셋 리스트 (프로토타입 1판 기준, ~15장)

| 분류 | 수량 |
|---|---|
| 탱커 | idle + 방어 포즈 |
| 아군 | 딜러 1, 힐러 1 |
| 적 | 2~3종 각 1장 |
| 배경 | 던전 1장 |
| UI | 스킬 아이콘 3~4, 인텐트 화살표, HP바 |

에셋 생성 규칙: 스타일 가이드 프롬프트 고정 재사용 / 전부 오른쪽 바라보기(적은 좌우 반전) / 단색 배경으로 뽑고 후처리로 투명화 / 캔버스 비율·캐릭터 높이 비율 통일.

### 프로토타입 v0 플레이테스트에서 발견한 것 (2026-08-15)

- 초반 3~4턴은 "누굴 구하나" 선택이 실제로 발생 — 검증 질문(3턴째 고민) 통과로 보임. 단 유저 직접 플레이로 재확인 필요.
- **마지막 적 하나만 남으면 긴장이 0이 됨** (도발-힐-딜 반복이 자명해짐). 후반 압박 장치 필요: 브루트 격노(저HP 시 2회 공격/광역), 증원, 턴 제한 등.
- 힐러가 적 페이즈 *전에* 행동해서 1턴 힐이 낭비됨 — 행동 순서 재고 (힐을 적 페이즈 후로, 또는 힐 대상도 인텐트로 예고).
- MCP RunCommand 스니펫은 System.Reflection 금지 — 필요하면 프로젝트 에디터 스크립트에 넣고 호출로 우회.
