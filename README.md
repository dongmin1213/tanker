# 탱커 (가제)

> 공격 스킬이 하나도 없는 탱커가 되어, AI 팀원들을 지키며 던전을 클리어하는 모바일 턴제 게임.

## 현재 상태 (2026-08-17 — v1.0)

- **v1.0 — 콘텐츠 대확장**: 클래스 **20종** · 적 **32종 + 보스 5종**(막마다 2종 중 랜덤, 3막 최종 보스 심연의 용) ·
  카드 **40종**(강화 포함 80변형) · 유물 **30종** · 이벤트 **12종** · **3막(나락)**.
  신규 축: 독(DoT)·석화·카드 봉인·잠복·분열·피해 전가·회복 차단·관통, 지속 카드·자원 카드(턴당 1카드 예외)·조건부 카드.
  규칙은 `docs/design.md` v1.0.

## 이전 상태 (2026-08-17 — v0.9)

- **v0.9 — 진형과 AI v3**: 전열/후열 배치(파티 화면 토글, 근접 전열 +1/후열 -1, 원거리 무관),
  적 이동 태그(근접=전열 우선/도약=배치 무시), 늑대 무리 집중 사냥, 아군 킬각 가중치(폭탄 임박·지휘 오라 최우선).
  규칙은 `docs/design.md` v0.9.

## 이전 상태 (2026-08-17 — v0.8)

- **v0.8 — 2막과 도감**: 워로드 격파 후 **귀환(승리)/심층(2막)** 선택 — 세션 15분/완주 30분. 2막 끝에 **최종 보스
  리치 왕**(사령 폭풍 — 탱커 포함 전원) → 진엔딩. 적 +4(방패병·늑대·미믹·저주 갑옷, 합계 19+보스 2).
  **도감**(아군/몬스터/유물 전부 공개) + **내 상태**(유물·파티·덱 오버레이). 전투 하단 재구성(필드 +130px),
  상점 언어 버그·언어 즉시 적용 수정. UI 돌+금 재톤 + 신규 유닛 11시트 에셋 통합 대기.
- **BGM**: `unity/Assets/Resources/Audio/bgm-dungeon.(ogg|mp3|wav)`를 넣으면 자동 적용 (Suno 트랙용 훅) — 없으면 절차 합성 폴백.

  3관점(고인물/PM/사업가) 리뷰 반영 — 사업 로드맵: 3막·보스 3종 갖춘 뒤 유료, 그 전까진 TestFlight 검증.

## 이전 상태 (v0.6, 2026-08-16)

- **v0.6 — 던전에 깊이**: 일직선 7노드 → **StS식 8층 분기 맵**(층당 2~3방, 연결된 방만 탭 전진, 엘리트/상점/보물/함정/휴식

  codex 비주얼 크리틱 15건 반영. 규칙은 `docs/design.md` v0.6.

## 이전 상태 (v0.5, 2026-08-16)

- **v0.5 — 유저 1차 플레이 피드백 반영**: ① 전투 AI v2(아군 킬각 집중·힐러 위험권 우선, 적은 처치 가능 백라이너 조준 — 인텐트로 예고) ② 전 화면 설정 오버레이(BGM/효과음 볼륨·언어·타이틀 복귀 2단 확인) + **절차 합성 사운드**(칩튠 BGM 루프 + 효과음 7종, 외부 에셋 0) ③ 전 화면 UI 단장(던전 맵 지그재그 경로+노드 아이콘+파티 스트립, 엔딩 연출, 배너/프레임 통일) ④ **풀 확장 — 전부 고유 매커니즘**: 클래스 10종(+성기사/광전사/음유시인), 적 12종(+가시 골렘/흡혈 박쥐/네크로맨서), 카드 12종(+철의 의지/수호 낙인/숨 고르기). 규칙은 `docs/design.md` v0.5.
- 신규 유닛 6종 시트(12장) 통합 완료 — 총 유닛 시트 39장, 전부 codex 생성 + pixelize 파이프라인.

## 이전 상태 (v0.4, 2026-08-16)

- **v0.4 대격변 (코어 가동 확인)** — 유저 지시로 라이브 지향 개편:
  **랜덤 파티**(나 + 클래스 7종 중 2~4명, 시드 결정) · **적 풀 9종 + 예산 기반 랜덤 조우 + 스테이지 스케일링** ·
  **덱빌딩**(카드 9종, 매 턴 3드로우 1사용, 전투 보상으로 덱 성장, 상점 카드 제거). 파티 소개/카드 보상 화면 신규.
  스모크 검증: 5인 파티 생성 → 랜덤 조우(샤먼 저주 인텐트) → 카드 예약-커밋 해소 → 리셔플까지 인게임 확인.
- **발열 해결**: 프레임 캡 없던 것이 원인 — `targetFrameRate=60` + UI 텍스트 10Hz 스로틀 적용. 게임 자체는 가벼움.
- **신규 에셋 18종 통합 완료**(클래스 5·적 4 × idle/공격) — codex 생성 → pixelize 하단 정렬 → 인게임 확인까지.
- **TestFlight 라이브**: v0.4.0 빌드1 App Store Connect 업로드·처리 완료 (앱 "탱커 : 방패 원정대").
  업로드 파이프라인 전자동화 — 절차는 `docs/dev.md` 빌드 & TestFlight.
- 남은 것: v0.4 풀 런 밸런스 패스, 유저 폰 플레이 → 재미 판정.

## 이전 상태 (2026-08-15)

  확정 룰: 힐러는 백라이너 전담(탱커 치료 안 함) + 버티기 회복은 받은 만큼 후불. 전투별 최적 상한 측정으로 "어렵지만 공정" 판정.
- **아키텍처 규약(신규)**: VSA 슬라이스(Battle/Run/Shared), 밸런스 수치는 `Resources/balance.json` 단일 출처(하드코딩 금지),
  다국어 ko/en(`Loc`, 타이틀에서 전환), 최적화 최우선 검토. macOS 스탠드얼론 빌드 검증 완료(빌드 시점 씬 생성).

## 구조

```
tanker/
├─ unity/                 # Unity 프로젝트 — VSA 슬라이스: Scripts/Battle(전투)·Run(런)·Shared(UiKit/Balance/Loc/부트)
│                         #   수치는 Resources/balance.json, 문자열은 Loc(ko/en), 에셋은 Resources/Art
├─ tools/
│  ├─ mcp_unity.py        # Unity MCP stdio 클라이언트 (Claude 개발 루프용)
│  ├─ unity-snippets/     # RunCommand 스니펫 (play/stop/refresh/상태/캡처 등)
│  └─ pixelize.py         # AI 생성 이미지 → 게임용 픽셀 스프라이트 후처리
└─ docs/
```
