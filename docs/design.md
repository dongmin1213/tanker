# 게임 디자인

> 소유 주제: 컨셉, 디자인 원칙, 전투 규칙, 밸런스 수치, 플레이테스트 발견, 열린 디자인 질문.

## v1.0 밸런스 패스 1차 (2026-08-18) — 실전 코드 시뮬 기반

### 새 검증 도구: `TankerBalanceSim` (v0.3 탐색기 폐기)

기존 `TankerBalanceSearch`는 3인 파티·스킬 3개 시대 전용이라 지금 판(클래스 20·카드 40·유물 30·진형)엔 쓸 수 없었다.
새 시뮬은 **실제 `BattleManager`를 그대로 돌린다** — `EndTurnHeadless()`로 해소 코루틴을 직접 펌프하므로
검증기와 실게임의 규칙 드리프트가 원천적으로 불가능하다 (v0.3.2의 최대 약점 해소).
배치모드: `-executeMethod Tanker.BalanceSim.BatchRun` (`TANKER_SIM_RUNS`로 횟수).
정책은 "합리적 플레이어" 휴리스틱 — 예상 피해를 읽고 동료 즉사 > 탱커 위기 > 화력 순으로 카드 선택.

### 발견과 조치 (0% → 27%)

시작 상태는 **1막 격파율 0%**였다. 저HP 동료가 1~2턴에 즉사 → 즉시 패배가 반복.

| 발견 | 조치 |
|---|---|
| 층 8→10 확장 후 조우 예산이 과대(항상 4마리 최대 코스트) | `encounterBudgetBase` 5→3, `PerStage` 2→1, 스케일 `scaleHpPct` .08→.06 / `scalePowerStages` 3→4 |
| 탱커는 1턴 1명만 보호 가능한데 위협이 3~4개 | 적 수 상한 도입(초반 3, `encounterCapStage`=6부터 4), 도약형 최대 2, 카운터형 최대 2 |
| 저HP 동료가 적 2타에 즉사 | 하한 상향(암살자 11→13, 마법사·그림자·점술사 12→14, 음유시인·독술사 13→15, 도적 15→16) |
| 같은 아군에 적이 몰려 1턴 즉사 | **집중 상한 규칙**: 단일 공격 적은 이미 둘이 노리는 아군을 피한다(도약형 예외) |
| 감산 스택으로 전투가 무손실화 | **확정 규칙: 감산·절반으로는 0이 되지 않는다(최소 1)**. 완전 무효는 방패·축복·최후의 저항만 |
| 다중 위협에 대응할 시작 수단 없음 | 시작 덱 개편: 엄호 2 → 엄호1 + **결사 방어1**(광역 감산) |
| 진형이 화력 축으로만 기울어 공격 진형 독주(66%) | 공격 진형에 **받는 피해 +1** 대가, 보호 진형 감산 1→2 + **근접 1회 가로채기**, 밸런스 진형 창끝 감산 2 |
| 파티 2명 구성이 구조적으로 취약 | `partyMinCompanions` 2→3 |

### 현재 지표 (40런, 합리적 플레이 대역)

- **1막 보스 격파율 27%**, 2막 도달 27%, 평균 도달 층 7.4/10, 전투당 3.1턴
- **후반(5층+·2막) 무손실 전투 18%** — 게이트(20%) 통과. 전체 무손실 25%는 초반 약한 조우 포함값
- 진형별 격파율 기본 33 / 밸런스 10 / 공격 41 / 보호 22 — 독주는 해소, **밸런스 진형은 여전히 약함(다음 과제)**

판정: "어렵지만 공정" 쪽. 시뮬 정책은 사람보다 보수적이므로 실제 체감은 더 높을 것으로 보되,
**남은 과제**는 ①밸런스 진형 재설계 ②1턴 즉사 잔존 케이스(도약형 2마리 + 저격 조합) ③3막 도달률 0% (2막 난도 절벽).

### 통제 비교에서 드러난 착시 (중요)

진형을 무작위 배정한 채 비교한 1차 수치(공격 41% vs 밸런스 10%)는 **파티 구성 운이 섞인 착시**였다.
같은 시드 집합에 진형만 고정해 다시 돌리자 기본 16 / 밸런스 27 / 공격 22 / 보호 27로 편차가 훨씬 작았고,
최하위는 오히려 "표준"인 기본 진형이었다. → **밸런스 판단은 반드시 변수를 고정한 통제 비교로 한다**
(`BalanceSim.BatchFormations`, `ForcedFormation`).

### 2막 절벽

모든 진형에서 3막 도달률 0%였다. 원인은 `actStageBonus` 10 — 2막 1층 스테이지(10)가 1막 최종층(9)보다 높은데
막 전환 회복은 25%뿐이라 난도가 수직 상승했다. → `actStageBonus` 7, `descendHeal` 0.4로 완화.

### 60런 기준선 (2026-08-18)

격파율 28% · 평균 도달 7.8/10층 · 전투당 3.3턴 · 후반 무손실 22% · 3막 도달 1%.

**남은 판단은 유저 실제 플레이 데이터로**: 엔딩 통계의 플레이 시간·도달 층이 이 시뮬 기준선과 얼마나 다른지가

## v0.9 — 진형(전열/후열)·AI v3 (2026-08-17, 유저 지시 "세븐나이츠식 배치 + AI 지능 상향")

### 진형 — 배치가 첫 수읽기가 된다

- **진형 프리셋** (유저 지시 — 세븐나이츠식 프리셋 선택, 개별 토글 아님): 파티 화면에서 4종 중 택1,
  배치(Rows)는 프리셋에서 파생. 탱커는 항상 전열. 런 도중 변경 불가 — RunState.Formation/Rows 저장·복원.
  | 진형 | 배치 | 패시브 (balance) |
  |---|---|---|
  | 기본 | 근접 전열 · 원거리 후열 | — |
  | 밸런스 | 최강 근접 1명만 전열 (창끝) | — |
  | 공격 | 전원 전열 | 전원 공격 +formAtkBonus(1), 전원이 근접 표적 |
  | 보호 | 전원 후열 (탱커만 전열) | 동료 받는 피해 -formGuardReduce(1), 근접 적이 후열 직행 |
  패시브는 AllyDamage/ComputeDamage 공용 계산에 들어가 예측=해소 자동 미러.
- **위치 효과** (balance: rowFrontBonus/rowBackPenalty = 1): 근접 클래스(전사·도적·암살자·수인·문지기·그림자·성기사·광전사)는
  전열 공격 +1 / 후열 -1(최소 1). **원거리 클래스(마법사·궁수·음유시인·클레릭)는 배치 무관** — "근접을 앞에 세우고 싶지만
  얻어맞는다"는 트레이드오프가 코어. 보정은 배율 특성(광폭·만전 등) **앞**에 적용 — 전열 광전사가 의도적으로 강하다.
- **적 이동 태그**: 근접(기본) = 전열 아군이 살아있으면 전열만 노림 — **모든 단일 공격 근접 AI가 같은 후보 판정(RowBlocked) 공유**
  (기회형·집요형 고블린, 오크, 미믹, 슬라임, 브루트, 방패병, 갑옷 등) / **도약·매복**(거미·박쥐·늑대·매복 고블린) = 배치 무시 /
  저격·주술(궁수·샤먼·네크로·보스·폭탄꾼·도굴꾼)은 고유 AI 유지. **전열을 비워 배치하면** 근접도 후열로 온다 —
  탱커가 자동 벽이 되진 않는다(도발이 도구). (전투 중 전열 전멸 전환은 사망 즉시 패배 규칙상 발생하지 않음)
- **아군 공격 연산 순서 확정**: 기본공격 + 진형 + 군기 → **위축 절반**(이번 행동 전체의 절반) → 배율 특성(광폭·만전·선제) → 기세 가산.

## 컨셉

공격 스킬이 하나도 없는 탱커가 되어, 완전 AI인 팀원들을 지키며 던전을 클리어한다.
턴제, 싱글플레이, 모바일 세로 고정. 셀링 포인트: **수읽기로 하는 탱킹** — 예고된 재앙을 비틀어 팀을 살린다.

## 디자인 원칙

1. **적의 인텐트는 항상 공개** — 적→타겟 화살표 + 예상 데미지. 수읽기 게임의 전제.
2. **스킬 사용 시 화살표가 나에게로 휘는 미리보기** — 이 게임의 "타격감". 예약-커밋 구조로 구현됨: 진행 전 자유 취소/교체.
3. **어그로는 자원** — 도발엔 쿨다운이 있어 "누굴 구할지" 강제 선택이 생긴다.
4. **내 HP가 소모 자원** — 맞아주는 것 자체가 지출.
5. **팀원은 맞으면 위축** — 보호가 곧 DPS라는 등식.
6. **방어 피드백이 공격보다 크게** — 막아낸 피해가 점수판. 탱커 피격 시에만 화면이 흔들린다.

## 현재 규칙 요약 (v0.8 구현 기준)

현재 판의 규칙은 위 버전 절들의 델타 합이다. 한눈 요약:

- **행동 = 카드**: 매 턴 4드로우 1사용(선택), 카드 16종 + 전부 강화(+) 버전. 시작 덱 6장, 전투 보상·상점으로 성장.
  원형 3스킬(도발/엄호/버티기)의 규칙 — 예약-커밋, 인텐트 최종값 표시, 보호 점수 — 은 카드 위에서 그대로 유지.
- **파티**: 탱커 + 12클래스 중 2~4명 랜덤(시드), 전원 고유 특성(v0.7 표). 첫 런은 전사+클레릭 고정.
- **적**: 19종 + 보스 2(1막 오거 워로드, 2막 리치 왕) — 전원 고유 매커니즘, 예산 기반 랜덤 조우 + 층 스케일링.
- **런**: 8층 분기 맵(DAG) ×2막, 방 완료마다 자동 저장. 골드/상점/휴식(회복 or 강화)/이벤트 3종/유물 10종.
- **불변 원칙**: 예측=해소(PredictKills·IncomingPreview는 Resolve와 같은 규칙을 미러), 수치는 balance.json 단일 출처.

### 탱커 스킬 (턴당 1개)

| 스킬 | 효과 | 제한 |
|---|---|---|
| 도발 | 적 1명이 2턴간 나만 공격 (사용 턴 포함 2턴, 차징 턴에도 차감) | 쿨 3턴 = 사용 턴 포함 3턴 주기 (T1 사용 → T4 재사용) |
| 엄호 | 이번 턴, 지정 아군을 노리는 공격을 내가 대신 맞음 | 없음 |
| 버티기 | 이번 턴 받는 피해 절반, **받은 피해만큼 후불 회복(최대 3)** — 적 페이즈 후 적용 | 없음 |

- **예약-커밋**: 스킬 선택은 '진행' 전까지 예약일 뿐이다. 자유롭게 취소·교체 가능, '진행'이 유일한 확정점 (실행취소 원칙 충족).
- **인텐트의 예상 피해는 최종값**: 도발/엄호/버티기(예약 포함)를 반영해 실제 받을 피해를 표시한다.
- **보호 점수**: `대신 맞음`(아군 대신 실제로 받은 피해)과 `경감`(버티기·철벽 엄호·도발 함성으로 줄인 피해)을 분리 집계·표기.

### 턴 순서

인텐트 공개 → 플레이어(스킬 0~1개 + 진행) → 딜러(HP 최저 적 공격) → 적 전원(인텐트 실행, 도발/엄호 반영)
→ 버티기 후불 회복 → 힐러(**백라이너 중** HP 최저 치료 — **탱커는 치료 대상이 아니다**) → 위축·쿨다운·격노 갱신 → 다음 인텐트.

- **탱커 회복 수단은 버티기(받은 만큼)·휴식·물약뿐** — 탱커 HP가 진짜로 소모 자원이 되게 하는 핵심 규칙 (v0.3.2).

- 아군이 피격되면 **위축**: 다음 행동 효과 절반. 탱커는 위축 없음.
  세부: 중첩 없음(bool). 딜러는 적보다 먼저 행동하므로 **다음 턴** 공격이 절반, 힐러는 적 뒤에 행동하므로 **같은 턴** 치료가 절반 (의도된 비대칭).
- 승리: 적 전멸 — 마지막 적이 죽는 **즉시** 판정. 패배: 아군(탱커 포함) 아무나 사망 — 죽는 **즉시** 판정, 남은 행동·연출은 중단.

## 런 구조 원형 (v0.3 선형 7노드 — 역사 기록, 현행은 v0.6 분기 맵 + v0.8 2막)

타이틀 → 던전 맵(7노드 선형) → 엔딩. 아군 3인의 HP는 **노드 사이에 유지**된다 (탱커 HP = 런의 수명 자원).
아군 사망 = 런 즉시 종료. 위축은 전투 종료 시 해제.

| # | 노드 | 내용 |
|---|---|---|
| 1 | 전투: 고블린 매복 | 고블린A(힐러 고정 4) + 고블린B(딜러 고정 4) + 브루트(백라이너 교대 강타 8, 홀수 턴 차징) |
| 2 | 이벤트: 가시 함정 복도 | 결정론적 선택 — (a) 내가 앞장선다: 탱커 -6 (b) 우회로 통행료: 골드 -20 (c) 딜러를 보낸다: 딜러 -4 + 다음 전투 위축 시작. **비전투 피해도 진짜 피해 — 0이 되면 런 즉시 종료** |
| 3 | 전투: 백라인 사냥 | 스켈레톤 궁수(힐러 고정 5) + 고블린×2(딜러 고정 4 / 최저 백라이너 4) |
| 4 | 갈림길 | 휴식 **또는** 상점 중 택 1 |
| 5 | 전투: 쌍둥이 브루트 (엘리트) | 브루트X(홀수 차징·짝수 강타 8) + 브루트Y(짝수 차징·홀수 강타 8) — 매턴 강타가 온다 |
| 6 | 휴식 | 전원 최대 HP 30% 회복 |
| 7 | 보스: 오거 워로드 → 엔딩 | 아래 보스 패턴 참조. 고블린 1 동반 |

- **골드**: 일반 전투 승리 +40, 엘리트 +40, 보스 0. 시작 0. (상점 도착 시 80G 또는 통행료 후 60G — 2개까지 구매 가능)
- **휴식**: 전원 최대 HP의 30% 회복.
- **상점** (1회): 도발 함성(도발된 적에게 받는 피해 -2, 40G) / 철벽 엄호(엄호로 대신 맞는 피해 -2, 50G) / 단단한 각오(버티기 회복 +2, 40G) / 응급 물약(즉시 탱커 20 회복, 30G). 골드 내 다중 구매 가능.
- **보스: 오거 워로드** — HP 45, 공개 3턴 패턴 사이클: ① 차징 → ② 광역 휩쓸기(생존 백라이너 전원에게 5) → ③ 강타(딜러 우선 10). HP≤24 격노: 차징 없이 ②③ 교대, 첫 격노 행동은 광역.
  - **광역 규칙**: 엄호는 지정 아군 몫만 리다이렉트(나머지는 그대로 맞음). 인텐트 라벨은 수신자별 최종 피해를 표시.
  - **도발된 보스**: 차징 턴은 그대로 쉬고(도발 소모됨), 광역/강타 턴은 탱커 단일 강타(10)로 변환.
  - **피해 감소 순서 규칙**: 가산 감소(도발 함성/철벽 엄호) → 배율 감소(버티기 절반, 내림), 최소 0. 철벽은 엄호가 원인인 리다이렉트에만, 함성은 도발이 원인일 때만 — 중첩 없음.
- 적 타겟 분산(리뷰 D-01 대응): 고정 타겟(힐러/딜러)과 교대 패턴을 섞어 **매턴 복수의 위협**이 생기게 한다. 수치는 시뮬레이션 후 확정.

## 밸런스 게이트 확정 (v0.3.2, 2026-08-16)

레포 내장 결정론 탐색기(`TankerBalanceSearch`, 수치는 Balance 공유)로 게이트를 재검증하고 룰을 확정했다.

- **기준선 재현**: Cover-only 승리선(최고 24/13/8), Taunt+Brace 무손실(40/18/14) — codex 반례를 자체 도구로 독립 재현.
- **레버 실험**: 엄호 첫타 제한/보스 관통/버티기 후불 단독으론 게이트 못 닫음. 무손실 엔진의 회복원은
  힐러 5힐 + 버티기 즉시회복의 **이중 소스**였음.
- **확정 룰 (v0.3.2)**: ① 힐러는 백라이너 전담(탱커 치료 안 함) ② 버티기 회복은 받은 피해만큼 후불(최대 3+각오).
  결과 — Taunt+Brace 무손실 제거(최고 30/10/14), Cover-only는 최적 탐색조차 전 파티 빈사(7/6/5)로만 통과, 탐욕 실행은 사망.
- **게이트 판정 기준 (codex 원안 "승리선 0"에 대한 반박 채택)**: 결정론 퍼즐에서 최적 탐색 승리선의 원천 제거는
  액션 셋 부정과 같다. 실질 기준 = ⓐ 무손실 엔진 부재 ⓑ 탐욕(그리디) 단일 정책 실패 ⓒ 자원 소모 강제 — 세 조건 달성.
- Mixed(전체 액션) 전수 탐색은 풀 런 체인에선 상태 폭발로 불가하나 **단일 전투는 가능** (`ProbeBattle`).
- **전투별 인간 최적 상한 (v0.3.2 수치, 물약 20·휴식 30%)**: 전투1 40→38(탱커 -2)/ 전투2 30진입→22 / 엘리트 30진입→29 / 보스 34진입→25.
  예산상 좋은 플레이는 여유 있게 완주 가능 — 반면 휴리스틱 봇은 전투1에서 -28을 소모하고 전투2에서 사망.
  **판정: 어렵지만 공정.** 최적(-2)과 범부(-28)의 격차가 곧 수읽기 스킬 표현력. 봇 회귀는 봇 한계로 기록하고,
  실제 난이도 체감은 유저 플레이 판정으로 넘긴다. (탱커 회복원이 사라졌으므로 초견 사망은 장르 정상.)

**v0.4 진입 조건 (콘텐츠 추가보다 우선)** — 3차 감사의 결정론 탐색이 확인한 잔존 밸런스 이슈:

1. **Cover-only 최적 탐색 승리선 제거** — 철벽+물약 구매 경로가 최적 시퀀스로는 여전히 완주 (탐욕 버전은 사망 — "사람이 쉽게 찾는 정답"은 아니나 존재 자체가 문제).
2. **도발 함성+단단한 각오의 도발→버티기 무손실 엔진 제거** — 감소 스택(함성-2, 버티기 절반) 후 피해 < 힐러 5힐+버티기 회복이면 무한 유지.
   근본 원인은 아이템 수치가 아니라 **힐러 자동 힐 + 탱커 단일 타겟 위협의 조합** — 적 측 해법(버티기 관통 강타, 힐 압박 패턴 등) 룰 실험으로 풀 것.
3. **Preview-Resolve 이벤트 계산 통합** — 예측 조각 함수 방식은 새 패턴마다 드리프트 재발.
4. **자동 검증 정책의 코드화** — 제한 탐색(Cover-only/Taunt+Brace/업그레이드 쌍별)을 회귀 테스트로 고정.

- **codex 정적 리뷰 (2026-08-15)**: `엄호(딜러) 매턴 반복`이 최단 8턴 승리를 만드는 **지배 전략** — 현재 판은 수읽기보다 "정답 정책 발견" 퍼즐에 가깝다.
  원인: 고블린B·브루트가 모두 딜러 우선이라 위협이 딜러 한 명에 수렴. 격노도 최적 경로에선 1회 공격에 그침.
